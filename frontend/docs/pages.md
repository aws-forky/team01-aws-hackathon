# Frontend Pages

## 역할
각 라우트에 대응하는 페이지 컴포넌트들을 정의합니다.

## 주요 페이지

### 1. SetupPage
- 서비스 소개 및 사용법 안내
- Forky 캐릭터와 함께하는 친근한 온보딩
- "시작하기" 버튼으로 업로드 페이지 이동
- 서비스 특징 및 장점 설명

### 2. UploadPage
- 드래그앤드롭 파일 업로드 인터페이스
- PDF 파일 검증 및 업로드 진행률 표시
- Upstage Document Parser 분석 상태 표시
- 분석 완료 후 자동으로 회사 선택 페이지 이동

### 3. CompanyPage
- 대기업 프리셋 목록 (네이버, 카카오, 삼성전자 등)
- 사용자 정의 회사 추가 기능
- 회사별 특징 및 기술 스택 미리보기
- 선택 완료 후 질문 생성 시작

### 4. InterviewPage
- 생성된 질문 목록 표시
- 질문별 모범답안 토글 기능
- 진행률 표시 및 질문 네비게이션
- 북마크 및 메모 기능
- 완료 후 결과 페이지 이동

### 5. ResultPage
- 전체 질문/답안 요약 화면
- PDF 다운로드 기능 (jsPDF + html2canvas)
- 다시 시작하기 버튼
- 피드백 및 개선사항 제안

## 특징
- 단계별 워크플로우 구현
- 상태 관리 및 데이터 전달
- 로딩 상태 및 에러 처리
- 반응형 디자인
- PWA 오프라인 지원
