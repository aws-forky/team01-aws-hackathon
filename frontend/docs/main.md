# Frontend Main Application

## 역할
React 애플리케이션의 진입점 및 전체 구조를 관리합니다.

## 주요 기능
- React 앱 초기화 및 렌더링
- 라우터 설정 (React Router v6)
- 전역 상태 관리 (Context API)
- 테마 및 스타일 설정 (Tailwind CSS)
- PWA 서비스 워커 등록

## 구성 요소
- App 컴포넌트 (메인 레이아웃)
- 라우터 설정 (4단계 워크플로우)
- 전역 컨텍스트 (사용자 데이터, 상태)
- 에러 바운더리
- 로딩 스피너 및 전역 UI

## 라우트 구조
- `/` - 설정 페이지 (서비스 소개)
- `/upload` - 업로드 페이지 (파일 업로드)
- `/company` - 회사 선택 페이지
- `/interview` - 면접 페이지 (질문/답안)
- `/result` - 결과 페이지 (요약/다운로드)
