# Frontend Components

## 역할
재사용 가능한 UI 컴포넌트들을 정의합니다.

## 주요 컴포넌트

### 1. Layout Components
- `Header` - 상단 네비게이션 및 로고
- `Footer` - 하단 정보 및 링크
- `Sidebar` - 사이드 메뉴 (모바일 대응)
- `Layout` - 전체 페이지 레이아웃 래퍼

### 2. Form Components
- `FileUpload` - 드래그앤드롭 파일 업로드
- `CompanySelector` - 회사 선택 드롭다운
- `ProgressBar` - 진행률 표시
- `Button` - 공통 버튼 컴포넌트

### 3. Content Components
- `QuestionCard` - 질문 카드 (질문/답안 표시)
- `KeywordBadge` - 키워드 태그
- `LoadingSpinner` - 로딩 애니메이션
- `ErrorMessage` - 에러 메시지 표시

### 4. Character Components
- `ForkyCharacter` - Forky 캐릭터 이미지
- `SpeechBubble` - 말풍선 컴포넌트
- `GuideMessage` - 안내 메시지

### 5. Utility Components
- `Modal` - 모달 다이얼로그
- `Toast` - 알림 메시지
- `Tooltip` - 툴팁
- `Accordion` - 접기/펼치기 컴포넌트

## 특징
- TypeScript 타입 안전성
- Tailwind CSS 스타일링
- 반응형 디자인 지원
- 접근성 (a11y) 고려
- 재사용성 및 확장성
