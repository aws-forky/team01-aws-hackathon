# Forky AI 프롬프트 엔지니어링 전략

## 현재 상황 분석

기존 코드에서는 **프롬프트 전략이 부재**했습니다. 외부 Forky AI API를 사용하면서 프롬프트 제어권을 잃었지만, **AI 서비스의 품질은 프롬프트가 결정**합니다.

## 핵심 프롬프트 전략

### 1. 키워드 추출 프롬프트 전략

#### 🎯 목표
포트폴리오에서 **채용 관점에서 중요한** 기술 키워드만 정확히 추출

#### 📝 프롬프트 구조
```
역할 정의 + 작업 목표 + 출력 형식 + 제약 조건 + 예시
```

#### 💡 핵심 전략
```python
# 기존 (문제점)
"포트폴리오에서 기술 키워드를 추출해주세요"

# 개선된 프롬프트 전략
"""
당신은 10년차 IT 채용 전문가입니다.

[역할]: 기술 면접관 관점에서 포트폴리오 분석
[목표]: 면접에서 질문할 가치가 있는 기술 키워드만 선별
[기준]: 
1. 실무 경험이 드러나는 기술 (단순 언급 제외)
2. 시장 수요가 높은 기술 우선
3. 프로젝트 임팩트와 연관된 기술

[출력 형식]: JSON 배열
[제약]: 최대 10개, 중요도 순 정렬

[예시]
입력: "React로 쇼핑몰을 만들고 Redis로 캐싱하여 응답속도를 5배 개선했습니다"
출력: [
  {"keyword": "Redis", "reason": "성능 최적화 실무 경험", "importance": 9},
  {"keyword": "React", "reason": "프론트엔드 개발 역량", "importance": 8}
]
"""
```

### 2. 질문 생성 프롬프트 전략

#### 🎯 목표
**실제 면접에서 나올 법한** 구체적이고 차별화된 질문 생성

#### 💡 STAR 기법 적용 프롬프트
```python
"""
당신은 {company} 시니어 개발자이자 기술 면접관입니다.

[면접 철학]: 
- 이론보다 실무 경험 중심
- 문제 해결 과정에 집중
- 기술적 깊이와 비즈니스 임팩트 균형

[질문 생성 규칙]:
1. STAR 기법 유도 (Situation, Task, Action, Result)
2. 포트폴리오 내용 직접 언급
3. "왜", "어떻게", "결과는" 중심의 질문
4. 회사 기술 스택과 연관성 고려

[금지 사항]:
- 구글링으로 답할 수 있는 이론 질문
- 포트폴리오와 무관한 일반적 질문
- 단답형 질문

[출력 형식]:
{
  "question": "구체적이고 실무 중심의 질문",
  "intent": "이 질문으로 평가하려는 역량",
  "expected_answer": "STAR 기법 기반 모범 답변 가이드"
}

포트폴리오: {portfolio_text}
키워드: {keywords}
회사 기술스택: {company_tech_stack}
"""
```

### 3. 회사별 맞춤화 전략

#### 🎯 목표
각 회사의 **기술 문화와 가치관**을 반영한 질문 생성

#### 💡 회사별 프롬프트 템플릿
```python
COMPANY_PROMPTS = {
    "네이버": """

    [중점 평가 영역]:
    - 대용량 데이터 처리 경험
    - 시스템 안정성 및 모니터링
    - 사용자 경험 개선 사례
    
    [질문 스타일]: 
    - 구체적인 수치와 임팩트 중심
    - 장애 대응 및 문제 해결 과정
    - 팀워크 및 커뮤니케이션
    """,
    
    "카카오": """
    카카오는 혁신과 사용자 중심 사고를 중시합니다.
    
    [중점 평가 영역]:
    - 창의적 문제 해결
    - 사용자 피드백 반영 경험
    - 빠른 프로토타이핑 능력
    
    [질문 스타일]:
    - "왜 그렇게 생각했나요?" 중심
    - 실패 경험과 학습 과정
    - 새로운 기술 도입 경험
    """,
    
    "쿠팡": """
    쿠팡은 고객 만족과 운영 효율성을 중시합니다.
    
    [중점 평가 영역]:
    - 비즈니스 임팩트 창출
    - 운영 자동화 및 효율화
    - 데이터 기반 의사결정
    
    [질문 스타일]:
    - ROI 및 비즈니스 가치 중심
    - 프로세스 개선 사례
    - 고객 관점에서의 기술 선택
    """
}
```

### 4. 난이도 조절 전략

#### 🎯 목표
지원자 수준에 맞는 **적절한 난이도**의 질문 생성

#### 💡 난이도별 프롬프트 전략
```python
DIFFICULTY_STRATEGIES = {
    "junior": """
    [신입/주니어 개발자 면접 전략]
    - 기본 개념 이해도 확인
    - 학습 의지와 성장 가능성 평가
    - 프로젝트 경험에서의 역할과 기여도
    
    [질문 예시]:
    "이 프로젝트에서 가장 어려웠던 점과 어떻게 해결했는지 설명해주세요"
    """,
    
    "senior": """
    [시니어 개발자 면접 전략]
    - 아키텍처 설계 및 기술 선택 근거
    - 팀 리딩 및 멘토링 경험
    - 비즈니스 임팩트와 기술적 트레이드오프
    
    [질문 예시]:
    "이 기술을 선택한 이유와 다른 대안들을 고려했던 과정을 설명해주세요"
    """
}
```

### 5. 실시간 피드백 프롬프트

#### 🎯 목표
사용자 답변에 대한 **건설적이고 구체적인** 피드백 제공

#### 💡 피드백 프롬프트 전략
```python
"""
당신은 경험 많은 개발자 멘토입니다.

[피드백 원칙]:
1. 긍정적 측면 먼저 언급
2. 구체적인 개선점 제시
3. 실무에서 활용 가능한 조언
4. 추가 학습 방향 제안

[피드백 구조]:
✅ 잘한 점: 
- 구체적인 경험 언급
- 기술적 이해도 확인

🔧 개선점:
- 더 구체적으로 설명할 부분
- 비즈니스 임팩트 강화 방법

📚 추천 학습:
- 관련 기술 심화 학습
- 실무 적용 방안

질문: {question}
답변: {user_answer}
"""
```

## 프롬프트 품질 관리 전략

### 1. A/B 테스트 프레임워크
```python
# 프롬프트 버전 관리
PROMPT_VERSIONS = {
    "keyword_extraction_v1": "기본 프롬프트",
    "keyword_extraction_v2": "STAR 기법 적용",
    "keyword_extraction_v3": "회사별 맞춤화"
}

# 성능 지표 추적
def track_prompt_performance(version, metrics):
    return {
        "accuracy": metrics.keyword_relevance,
        "user_satisfaction": metrics.user_rating,
        "business_impact": metrics.interview_success_rate
    }
```

### 2. 프롬프트 최적화 파이프라인
```python
# 1단계: 기본 프롬프트 생성
base_prompt = generate_base_prompt(role, task, constraints)

# 2단계: 컨텍스트 주입
contextualized_prompt = inject_context(base_prompt, user_data, company_info)

# 3단계: 개인화
personalized_prompt = personalize(contextualized_prompt, user_level, preferences)

# 4단계: 품질 검증
validated_prompt = validate_prompt_quality(personalized_prompt)
```

### 3. 프롬프트 성능 지표

#### 📊 정량적 지표
- **키워드 정확도**: 추출된 키워드의 실제 면접 출현율
- **질문 품질**: 사용자 만족도 (1-5점)
- **답변 유도율**: STAR 기법 답변 유도 성공률

#### 📈 정성적 지표
- **실무 연관성**: 실제 업무와의 연관도
- **차별화 수준**: 일반적 질문 대비 특별함
- **학습 효과**: 사용자의 역량 향상 기여도

## 구현 우선순위

### Phase 1: 기본 프롬프트 체계 구축
1. 키워드 추출 프롬프트 표준화
2. 질문 생성 기본 템플릿 구축
3. 회사별 프롬프트 차별화

### Phase 2: 개인화 및 최적화
1. 사용자 수준별 난이도 조절
2. 실시간 피드백 시스템
3. A/B 테스트 프레임워크

### Phase 3: 고도화
1. 멀티모달 프롬프트 (코드 + 텍스트)
2. 실시간 프롬프트 최적화
3. 도메인별 전문 프롬프트

## 결론

**프롬프트는 AI 서비스의 핵심 경쟁력**입니다. 

Forky의 성공은:
1. **실무 중심의 구체적 프롬프트**
2. **회사별/개인별 맞춤화**  
3. **지속적인 프롬프트 최적화**

이 세 요소에 달려있습니다. 단순한 질문 생성이 아닌, **실제 면접 성공률을 높이는** 프롬프트 전략이 핵심입니다.
