## 🎯 Forky 서비스 필요성 분석

### 1. 현재 면접 준비의 비효율성

#### 📈 정량적 데이터
```
기존 면접 준비 방식:
- 평균 준비 기간: 3개월
```

3. **회사별 차이 무시**: 획일적인 면접 준비
4. **피드백 부재**: 일방향적 학습

### 2. 기업 채용 프로세스의 문제점
