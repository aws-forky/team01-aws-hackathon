# Backend Main Application

## 역할
FastAPI 애플리케이션의 진입점 및 전체 설정을 담당합니다.

## 주요 기능
- FastAPI 앱 인스턴스 생성 및 초기화
- CORS 설정 (프론트엔드와의 통신 허용)
- 라우터 등록 (API 엔드포인트 연결)
- 미들웨어 설정 (로깅, 에러 처리)
- 애플리케이션 생명주기 이벤트 관리
- 환경 변수 및 설정 로드

## 구성 요소
- FastAPI 앱 설정
- 라우터 포함 (업로드, 분석, 질문 생성)
- 전역 예외 처리기
- 헬스체크 엔드포인트
- API 문서 설정 (Swagger/OpenAPI)
