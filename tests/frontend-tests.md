# Frontend Tests

## 역할
프론트엔드 컴포넌트와 사용자 인터랙션을 검증하는 테스트 코드를 정의합니다.

## 테스트 구조

### 1. Component Tests
- 개별 컴포넌트 렌더링 테스트
- Props 전달 및 상태 변경 테스트
- 이벤트 핸들링 테스트
- 조건부 렌더링 테스트

### 2. Integration Tests
- 페이지 컴포넌트 통합 테스트
- 라우팅 동작 테스트
- API 서비스 연동 테스트 (Mock)
- 상태 관리 테스트

### 3. E2E Tests
- 사용자 시나리오 테스트
- 파일 업로드 → 질문 생성 → 결과 다운로드
- 반응형 디자인 테스트
- PWA 기능 테스트

## 주요 테스트 케이스

### 컴포넌트 테스트
- FileUpload 드래그앤드롭 동작
- QuestionCard 토글 기능
- ProgressBar 진행률 표시
- Modal 열기/닫기 동작

### 페이지 테스트
- 각 페이지 정상 렌더링
- 페이지 간 네비게이션
- 데이터 전달 및 상태 유지
- 에러 상태 처리

### 사용자 시나리오
- 신규 사용자 온보딩 플로우
- 파일 업로드 및 분석 과정
- 질문 확인 및 답안 보기
- PDF 다운로드 기능

### 접근성 테스트
- 키보드 네비게이션
- 스크린 리더 호환성
- 색상 대비 및 가독성
- ARIA 속성 검증

## 테스트 도구
- Jest (테스트 프레임워크)
- React Testing Library (컴포넌트 테스트)
- MSW (API 모킹)
- Cypress (E2E 테스트)
- axe-core (접근성 테스트)
