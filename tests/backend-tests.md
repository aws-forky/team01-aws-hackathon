# Backend Tests

## 역할
백엔드 API의 기능과 로직을 검증하는 테스트 코드를 정의합니다.

## 테스트 구조

### 1. Unit Tests
- 개별 함수 및 메서드 테스트
- 서비스 로직 검증
- 모델 검증 및 직렬화 테스트
- 유틸리티 함수 테스트

### 2. Integration Tests
- API 엔드포인트 테스트
- 외부 API 연동 테스트 (Mock 사용)
- 데이터베이스 연동 테스트
- 파일 업로드/다운로드 테스트

### 3. E2E Tests
- 전체 워크플로우 테스트
- 파일 업로드 → 분석 → 질문 생성 전 과정
- 에러 시나리오 테스트
- 성능 테스트

## 주요 테스트 케이스

### API 테스트
- 파일 업로드 성공/실패 케이스
- 키워드 추출 정확성 검증
- 질문 생성 품질 검증
- 에러 응답 형식 검증

### 서비스 테스트
- Document Parser 연동 테스트
- Solar LLM 연동 테스트
- Fallback 시스템 동작 검증
- 캐싱 및 최적화 테스트

### 보안 테스트
- 파일 업로드 보안 검증
- API 키 보호 테스트
- Rate Limiting 동작 확인
- CORS 설정 검증

## 테스트 도구
- pytest (테스트 프레임워크)
- httpx (비동기 HTTP 테스트)
- pytest-mock (모킹)
- pytest-cov (커버리지)
- factory-boy (테스트 데이터 생성)
