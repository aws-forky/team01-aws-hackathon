# demo.py - Gradio 웹 데모

## 역할
AI Document Processing API의 기능을 사용자 친화적인 웹 인터페이스로 제공하는 Gradio 기반 데모 애플리케이션입니다.

## 주요 기능

### 1. 직관적인 웹 인터페이스
- 드래그 앤 드롭 파일 업로드
- 실시간 처리 상태 표시
- 결과를 단계별로 시각화
- 모바일 친화적 반응형 디자인

### 2. 완전 자동화 파이프라인 데모
- 파일 업로드부터 질문 생성까지 원스톱 처리
- 각 단계별 결과 실시간 표시
- 처리 시간 및 성능 정보 제공
- 오류 발생 시 친화적 메시지 표시

### 3. 결과 시각화 및 내보내기
- 추출된 키워드 태그 클라우드 형태 표시
- 면접 질문을 카테고리별로 구분 표시
- 결과를 JSON, PDF 형태로 내보내기
- 질문별 평가 가이드 툴팁 제공

## 인터페이스 구성

### 1. 파일 업로드 섹션
- **파일 선택**: 드래그 앤 드롭 또는 클릭으로 파일 선택
- **지원 형식**: PDF, DOCX, 이미지 파일 표시
- **파일 정보**: 선택된 파일명, 크기, 형식 표시
- **업로드 상태**: 진행률 바 및 상태 메시지

### 2. 회사 정보 입력
- **회사명 입력**: 선택적 회사명 입력 필드
- **자동완성**: 주요 IT 회사명 자동완성 기능
- **개인화 설명**: 회사명 입력 시 개인화 효과 안내

### 3. 처리 결과 표시
#### 문서 내용 섹션
- 추출된 텍스트 내용 표시
- 텍스트 길이 및 품질 정보
- 원본 파일과의 비교 기능

#### 키워드 섹션
- 추출된 키워드를 태그 형태로 표시
- 키워드별 중요도 시각화
- 폴백 사용 시 알림 표시

#### 면접 질문 섹션
- 기술면접 질문 (3개) 별도 표시
- 행동면접 질문 (2개) 별도 표시
- 각 질문의 평가 가이드 툴팁
- 질문별 난이도 표시

### 4. 추가 기능
- **결과 내보내기**: JSON, PDF 형태 다운로드
- **새로 시작**: 모든 입력 및 결과 초기화
- **예제 파일**: 샘플 포트폴리오 파일 제공
- **도움말**: 사용법 및 팁 제공

## 기술적 구현

### 1. Gradio 컴포넌트 활용
- `gr.File()`: 파일 업로드 인터페이스
- `gr.Textbox()`: 회사명 입력 및 결과 표시
- `gr.HTML()`: 키워드 태그 클라우드 렌더링
- `gr.Accordion()`: 결과 섹션 접기/펼치기
- `gr.Button()`: 처리 시작 및 내보내기 버튼

### 2. API 연동
- FastAPI 서버와 HTTP 통신
- `/api/v1/questions/process-complete` 엔드포인트 활용
- 비동기 처리로 사용자 경험 향상
- 오류 처리 및 재시도 메커니즘

### 3. 상태 관리
- 처리 단계별 상태 추적
- 진행률 표시 및 업데이트
- 오류 상태 처리 및 복구
- 사용자 입력 검증
