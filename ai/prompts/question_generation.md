# prompts/question_generation.json - 질문 생성 프롬프트

## 역할
Solar LLM이 포트폴리오와 키워드를 기반으로 신입 개발자에게 적합한 면접 질문을 생성할 수 있도록 설계된 프롬프트 템플릿을 관리합니다.

## 주요 기능

### 1. 전문적인 면접관 페르소나
- 10년차 이상 IT 전문 채용 담당자 역할 부여
- 기술 면접관으로서의 전문성 확보
- 신입 개발자 평가 경험 반영

### 2. 균형잡힌 질문 구성
- 기술적 질문 3개: 실무 능력 평가
- 행동 기반 질문 2개: 소프트 스킬 평가
- 총 5개 질문으로 종합적 평가 가능

### 3. 구조화된 질문 형식
- 각 질문에 고유 ID 부여
- 질문 유형 명시 (technical/behavioral)
- 질문 내용과 평가 가이드 포함

### 4. 개인화된 질문 생성
- 포트폴리오 내용 반영
- 추출된 키워드 활용
- 지원 회사 정보 고려

## 프롬프트 구조

### system_prompt
AI의 역할과 출력 형식을 정의하는 시스템 프롬프트

#### 페르소나 설정
- **역할**: 10년차 이상 IT 전문 채용 담당자
- **전문성**: 기술 면접관으로서의 경험
- **관점**: 신입 개발자 평가 전문가

#### 임무 정의
- 신입 개발자 적합 면접 질문 생성
- 기술적 질문 3개 + 행동 기반 질문 2개
- 균형있는 구성으로 종합 평가 가능

#### 출력 형식
JSON 스키마 명시:
```json
{
  "questions": [
    {
      "id": "q1",
      "type": "technical",
      "text": "구체적인 기술 질문 내용",
      "explanation": "면접관이 기대하는 답변 방향이나 평가 포인트"
    }
  ]
}
```

### user_prompt_template
구체적인 질문 생성 요청을 구성하는 템플릿

#### 입력 변수
- `{portfolio_text}`: 포트폴리오 전체 내용
- `{keywords}`: 추출된 핵심 기술 키워드
- `{company_info}`: 지원 회사 정보

#### 요청 구조
1. 포트폴리오 내용 제시
2. 핵심 기술 키워드 나열
3. 회사 정보 포함
4. 질문 생성 및 평가 가이드 요청

## 질문 생성 전략

### 1. 기술적 질문 (3개)
- **기술 스택 이해도**: 사용한 기술의 특징과 선택 이유
- **문제 해결 능력**: 직면한 기술적 문제와 해결 과정
- **개발 프로세스**: 버전 관리, 협업 도구 사용 경험

### 2. 행동 기반 질문 (2개)
- **팀워크**: 협업 경험과 갈등 해결 능력
- **동기와 목표**: 회사에 대한 이해와 기여 의지

### 3. 개인화 요소
- 포트폴리오에 언급된 구체적 기술 활용
- 프로젝트 경험을 바탕으로 한 실무 질문
- 지원 회사의 특성을 반영한 맞춤형 질문

## 평가 가이드 포함
각 질문마다 다음 요소 포함:
- **기대 답변**: 면접관이 듣고 싶어하는 답변 방향
- **평가 포인트**: 중점적으로 확인할 역량
- **추가 질문**: 답변에 따른 후속 질문 가이드

## 예상 응답 형식
```json
{
  "questions": [
    {
      "id": "tech_1",
      "type": "technical",
      "text": "React에서 상태 관리는 어떻게 하셨나요?",
      "explanation": "useState, useReducer 등의 이해도와 상태 관리 패턴 경험을 확인"
    },
    {
      "id": "behavioral_1", 
      "type": "behavioral",
      "text": "팀 프로젝트에서 의견 충돌이 있었다면 어떻게 해결하셨나요?",
      "explanation": "협업 능력과 갈등 해결 능력, 커뮤니케이션 스킬을 평가"
    }
  ]
}
```

## 프롬프트 최적화 포인트

### 1. 전문성 강조
- 면접관으로서의 경험과 전문성 부각
- 신입 개발자 평가에 특화된 관점

### 2. 구체성 확보
- 명확한 질문 개수와 유형 지정
- 상세한 JSON 스키마 제시

### 3. 맥락 활용
- 포트폴리오 내용을 질문에 반영
- 키워드 기반 기술적 질문 생성
- 회사 정보를 활용한 개인화

### 4. 실용성 중시
- 실제 면접에서 사용 가능한 질문
- 평가 가이드로 면접관 지원

## 사용 시나리오
1. 포트폴리오 텍스트, 키워드, 회사명 입력
2. 템플릿에 정보 삽입하여 프롬프트 구성
3. Solar LLM에 질문 생성 요청
4. JSON 응답 수신 및 파싱
5. 구조화된 면접 질문 목록 추출

## 품질 보장 전략
- 명확한 역할 정의로 일관된 품질
- 구체적인 요구사항으로 정확한 결과
- JSON 형식 강제로 파싱 안정성
- 평가 가이드 포함으로 실용성 확보
