# prompts/keyword_extraction.json - 키워드 추출 프롬프트

## 역할
Solar LLM이 포트폴리오 텍스트에서 기술 키워드를 정확하게 추출할 수 있도록 설계된 프롬프트 템플릿을 관리합니다.

## 주요 기능

### 1. 정확한 키워드 추출 유도
- 신입 개발자 포트폴리오에 특화된 프롬프트
- 5-10개의 핵심 기술 키워드 추출 지시
- 중요도와 관련성을 고려한 선별 유도

### 2. 구조화된 JSON 응답 강제
- 명확한 JSON 형식 지정
- `{"keywords": ["String"]}` 구조 강제
- 불필요한 설명이나 부가 텍스트 제거

### 3. 일관된 품질 보장
- 명확한 역할 정의 (포트폴리오 분석 전문가)
- 구체적인 출력 형식 지시
- 오직 JSON 객체만 반환하도록 제한

## 프롬프트 구조

### system_prompt
AI의 역할과 임무를 정의하는 시스템 프롬프트
- **페르소나**: 신입 개발자 포트폴리오 분석 전문가
- **임무**: 5-10개 핵심 기술 키워드 추출
- **출력 형식**: JSON 객체만 반환
- **제약사항**: 다른 설명 없이 순수 JSON만

### user_prompt_template
사용자 입력을 받아 구체적인 요청을 구성하는 템플릿
- **입력 변수**: `{portfolio_text}` - 분석할 포트폴리오 내용
- **요청 내용**: 5-10개 핵심 기술 스택 키워드 추출
- **형식 강조**: JSON 형식 필수 명시

## 프롬프트 엔지니어링 전략

### 1. 명확한 역할 부여
- "신입 개발자 포트폴리오 분석 전문가" 역할 명시
- 전문성과 신뢰성 확보

### 2. 구체적인 수량 지정
- "정확히 5개에서 10개 사이" 명시
- 너무 많거나 적은 키워드 방지

### 3. 출력 형식 강제
- JSON 스키마 명시적 제시
- "다른 설명 없이 오직 JSON만" 강조
- 파싱 오류 최소화

### 4. 품질 기준 제시
- "가장 중요한 핵심 기술 키워드" 강조
- 신입 개발자 관점에서의 중요도 고려

## 예상 응답 형식
```json
{
  "keywords": [
    "React",
    "JavaScript", 
    "Node.js",
    "Express",
    "MongoDB",
    "Git",
    "HTML",
    "CSS"
  ]
}
```

## 프롬프트 최적화 포인트

### 1. 간결성
- 불필요한 설명 제거
- 핵심 요구사항만 명시

### 2. 명확성
- 모호한 표현 배제
- 구체적인 수치와 형식 제시

### 3. 일관성
- 매번 동일한 형식의 응답 유도
- 파싱 가능한 구조 보장

## 사용 시나리오
1. 포트폴리오 텍스트 입력
2. 템플릿에 텍스트 삽입
3. Solar LLM에 프롬프트 전송
4. JSON 응답 수신 및 파싱
5. 키워드 목록 추출

## 오류 방지 전략
- JSON 형식 강제로 파싱 오류 최소화
- 키워드 개수 제한으로 과도한 결과 방지
- 명확한 지시로 일관된 품질 확보

- 프롬프트 성능 모니터링
