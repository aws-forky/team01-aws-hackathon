# 문제 해결 가이드

## 개요
AI Document Processing API 사용 중 발생할 수 있는 다양한 문제들의 해결 방법을 제공하는 종합 가이드입니다.

## 역할
- 일반적인 오류 상황별 해결 방법 제시
- 시스템 진단 및 디버깅 방법 안내
- 성능 문제 분석 및 최적화 가이드
- 외부 서비스 연동 문제 해결 방법

## 주요 내용

### 1. 일반적인 오류 해결

#### API 연결 오류
- **증상**: API 호출 시 연결 실패
- **원인**: 네트워크 문제, 서버 다운, 잘못된 URL
- **해결방법**: 
  - 헬스체크 엔드포인트 확인
  - 네트워크 연결 상태 점검
  - 서버 로그 확인

#### 인증 오류 (401 Unauthorized)
- **증상**: API 키 관련 인증 실패
- **원인**: 잘못된 API 키, 만료된 토큰
- **해결방법**:
  - 환경변수 설정 확인
  - API 키 유효성 검증
  - 토큰 갱신

#### 파일 업로드 오류 (413, 400)
- **증상**: 파일 업로드 실패
- **원인**: 파일 크기 초과, 지원하지 않는 형식
- **해결방법**:
  - 파일 크기 확인 (50MB 제한)
  - 지원 형식 확인
  - 파일 무결성 검증

### 2. AI 서비스 관련 문제

#### 키워드 추출 실패
- **증상**: 빈 키워드 목록 또는 오류 응답
- **원인**: 텍스트 품질 문제, LLM 서비스 장애
- **해결방법**:
  - 입력 텍스트 품질 확인
  - 폴백 키워드 활용
  - LLM 서비스 상태 점검

#### 질문 생성 실패
- **증상**: 질문 생성 불가 또는 품질 저하
- **원인**: 프롬프트 문제, 토큰 제한 초과
- **해결방법**:
  - 프롬프트 템플릿 검증
  - 토큰 사용량 최적화
  - 폴백 질문 활용

#### JSON 파싱 오류
- **증상**: AI 응답 파싱 실패
- **원인**: 잘못된 JSON 형식, 특수 문자
- **해결방법**:
  - 응답 전처리 강화
  - 파싱 로직 개선
  - 오류 로깅 강화

### 3. 성능 문제 해결

#### 응답 시간 지연
- **증상**: API 응답이 느림
- **원인**: 대용량 파일, 네트워크 지연, 서버 부하
- **해결방법**:
  - 파일 크기 최적화
  - 타임아웃 설정 조정
  - 서버 리소스 확장

#### 메모리 부족
- **증상**: 서버 메모리 부족으로 인한 오류
- **원인**: 대용량 파일 처리, 메모리 누수
- **해결방법**:
  - 파일 스트리밍 처리
  - 메모리 사용량 모니터링
  - 가비지 컬렉션 최적화

#### 동시 요청 처리 문제
- **증상**: 다중 요청 시 성능 저하
- **원인**: 동시성 제한, 리소스 경합
- **해결방법**:
  - 비동기 처리 최적화
  - 연결 풀 설정
  - 로드 밸런싱 구성

### 4. 외부 서비스 연동 문제

#### Upstage API 연동 오류
- **증상**: 문서 파싱 실패
- **원인**: API 키 문제, 서비스 장애, 요청 제한
- **해결방법**:
  - API 키 및 권한 확인
  - 요청 빈도 조절
  - 폴백 처리 활용

#### Solar LLM 연동 오류
- **증상**: LLM 응답 실패
- **원인**: 모델 서비스 장애, 토큰 제한
- **해결방법**:
  - 서비스 상태 모니터링
  - 요청 최적화
  - 대체 모델 고려

### 5. 환경 설정 문제

#### 환경변수 설정 오류
- **증상**: 설정값 인식 실패
- **원인**: .env 파일 누락, 경로 문제
- **해결방법**:
  - .env 파일 존재 확인
  - 환경변수 로딩 검증
  - 기본값 설정 확인

#### 의존성 설치 문제
- **증상**: 패키지 설치 실패
- **원인**: 버전 충돌, 네트워크 문제
- **해결방법**:
  - requirements.txt 확인
  - 가상환경 재생성
  - 패키지 버전 고정

### 6. 디버깅 도구 및 방법

#### 로그 분석
- 로그 레벨 설정 및 활용
- 구조화된 로깅 구현
- 로그 집계 및 분석 도구

#### 성능 프로파일링
- 응답 시간 측정
- 메모리 사용량 모니터링
- CPU 사용률 분석

#### 네트워크 진단
- API 호출 추적
- 네트워크 지연 측정
- 연결 상태 모니터링

### 7. 예방적 조치

#### 모니터링 설정
- 헬스체크 자동화
- 알림 시스템 구축
- 메트릭 수집 및 분석

#### 백업 및 복구
- 설정 파일 백업
- 데이터 백업 전략
- 복구 절차 문서화

#### 보안 강화
- API 키 정기 갱신
- 접근 로그 모니터링
- 보안 패치 적용
