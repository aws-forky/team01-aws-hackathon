# routers/health.py - 헬스체크 엔드포인트

## 역할
API 서버의 상태를 확인하고 모니터링하기 위한 간단한 헬스체크 엔드포인트를 제공합니다.

## 주요 기능

### 1. 서버 상태 확인
- API 서버가 정상적으로 실행 중인지 확인
- 빠른 응답으로 서버 가용성 검증
- 로드밸런서나 모니터링 도구에서 활용 가능

### 2. 간단한 응답 구조
- 최소한의 리소스 사용으로 빠른 응답
- 표준화된 성공 응답 형식
- 외부 의존성 없는 독립적인 동작

### 3. 모니터링 지원
- 서비스 배포 후 상태 확인
- CI/CD 파이프라인에서 배포 검증
- 운영 환경에서 지속적인 상태 모니터링

## API 엔드포인트

### GET /api/v1/health
**요청**
- 매개변수 없음
- 단순 GET 요청

**응답**
- BaseResponse 모델
- `success: true` - 서버 정상 동작
- `message: "API is running"` - 상태 메시지

## 사용 예시
```bash
curl -X GET "http://localhost:4700/api/v1/health"
```

## 응답 예시
```json
{
    "success": true,
    "message": "API is running"
}
```

## 활용 사례

### 1. 개발 환경
- 서버 시작 후 정상 동작 확인
- API 문서 접근 전 서버 상태 검증

### 2. 배포 환경
- 배포 스크립트에서 서비스 시작 확인
- 로드밸런서 헬스체크 엔드포인트로 활용

### 3. 모니터링
- 정기적인 서버 상태 점검
- 장애 감지 및 알림 시스템 연동

## 특징
- 외부 API 호출 없음 (빠른 응답)
- 데이터베이스 연결 불필요
- 최소한의 서버 리소스 사용
- HTTP 200 상태 코드 반환

## 확장 가능성
향후 다음과 같은 기능 추가 가능:
- 외부 API 연결 상태 확인
- 시스템 리소스 사용량 정보
- 서비스 버전 정보 포함
- 상세한 컴포넌트별 상태 체크
